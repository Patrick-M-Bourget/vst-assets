# Clones copy the look, not the brand

A Panel modeled on real hardware (the first is an LA-2A-style leveler) keeps the original's control set, layout and materials, so it reads as that unit, but carries our own name and wordmark. No third-party product name, company name or logo appears in any Render. Docs may describe a Panel as "LA-2A-style".

## Consequences

- A Look Brief notes the original's branding only to say what replaces it.
- Reviewing a Render includes checking for leftover third-party marks.
